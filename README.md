# ransomware-test-cybersec
Description Project developed for educational and cybersecurity study purposes, focusing on the mechanics of ransomware attacks and data recovery techniques (Blue Team). The simulation utilizes symmetric encryption via the Fernet library (AES-128) within a controlled environment.
